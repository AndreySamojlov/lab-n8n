# Job Searcher — Flows

Экспортированные JSON workflow проекта `Job Searcher`.

## Конвенции

- Имя файла: `<flow-slug>.v<N>.json`, напр. `remoteok-pipeline.v1.json`.
- Последняя версия дублируется как `<kebab-name>.latest.json`.
- Перед сохранением — **обязательная** валидация JSON против схемы `n8n-mcp`.
- Секреты — только как плейсхолдеры (`{{ $credentials.* }}` или `__SECRET__` с комментарием).

## Структура файла воркфлоу (минимум)

Помимо самого JSON, в начале файла/в сопроводительном `.md` рядом — краткая шапка:

- Назначение воркфлоу (1–2 предложения).
- Вход (триггер, формат данных).
- Выход (куда идут данные).
- Зависимости (какие credentials, внешние сервисы).
- История версий (что менялось от vN-1 к vN).

Тестовые артефакты добавим рядом с flow или в отдельный проектный раздел, когда практика проверок стабилизируется.
