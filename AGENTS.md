# lab-n8n — AGENTS.md

> Тонкий слой инструкций для Codex. Главный устав рабочего пространства — `CLAUDE.md`, дизайн практики — `DESIGN.md`.

## 1. Source of Truth

- Перед работой читай `CLAUDE.md` и, если задача затрагивает структуру практики, `DESIGN.md`.
- Общие правила обновляй только в `CLAUDE.md`.
- Устройство практики и проектный layout обновляй в `DESIGN.md`.
- `AGENTS.md` обновляется только когда появляется жёсткая специфика именно для Codex/agents, которую нельзя безопасно перенести в общий `CLAUDE.md`.

## 2. Codex-Specific

- Codex больше не ведёт отдельную авторскую папку для своих документов.
- AI-generated черновики можно временно складывать в `docs/AI-generated/`; полезное переносится в canonical-документы, мусор удаляется.
- При значимом изменении контекста не дублируй общий текст из `CLAUDE.md` или `DESIGN.md` сюда; добавляй сюда только минимальную Codex-дельту.
