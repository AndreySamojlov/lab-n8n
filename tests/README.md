# tests/

Тестовые кейсы и фикстуры для воркфлоу.

## Структура

```
tests/
└── <workflow-name>/
    ├── cases.md              ← описание кейсов (happy path, edge cases, failures)
    ├── input-<case>.json     ← входные данные кейса
    └── expected-<case>.json  ← ожидаемый результат
```

## Правила

- Каждый новый воркфлоу сопровождается **минимум одним happy-path кейсом**.
- Edge cases и failure cases добавляются по мере обнаружения багов (регрессионные тесты).
- В данных тестов — **никаких реальных секретов и реальных PII**. Только синтетика.
